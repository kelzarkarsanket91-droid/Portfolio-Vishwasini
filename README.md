# Vishwasini Bag — Portfolio

A personal portfolio site built with React, Vite, and Tailwind CSS.

## Edit the content

Everything on the site — name, bio, skills, education, projects, contact
info — lives in one file:

```
src/data/portfolioData.js
```

Open it and edit the text. No other file needs to change for content
updates. The three sample projects in there are placeholders — swap in
the real ones (title, tech stack, description, and an optional link).

## Run it locally

```bash
npm install
npm run dev
```

Then open the URL it prints (usually http://localhost:5173).

## Build for production

```bash
npm run build
```

This outputs a static site to the `dist/` folder. `npm run preview`
serves that build locally so you can check it before deploying.

## Deploy

Both `vercel.json` and `netlify.toml` are already set up — see the
deployment instructions provided alongside this project for the exact
steps on Vercel or Netlify.
